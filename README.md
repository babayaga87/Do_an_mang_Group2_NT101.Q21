# Đồ án Mạng - Nhóm 2 (Lớp NT101.Q21)

Đây là kho lưu trữ mã nguồn cho đồ án môn học NT101 - An toàn mạng.

## Tính năng chính
* Tính năng 1: Mã hóa và giải mã fairplay 5x5 và 6x6 
* Tính năng 2: Mã hóa và giải mã RSA

## 🛠️ Công nghệ sử dụng
* Ngôn ngữ: Python 3
* Thư viện chính: tkinter, 

## 💻 Hướng dẫn cài đặt và chạy
1. Tải mã nguồn về máy:
   ```bash
   git clone https://github.com
   ```
2. Di chuyển vào thư mục:
   ```bash
   cd Doanmang
   ```
3. Chạy chương trình:
   ```bash
   python Doanmang.py
   ```
